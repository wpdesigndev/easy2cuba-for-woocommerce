Privacidad

Tu privacidad

Última actualización: 15 de octubre de 2026

En resumen: esta web no usa cookies, no te pide datos y no te rastrea. El plugin no nos envía ningún dato de tu tienda ni de tus clientes.

Quién está detrás

Easy2Cuba for WooCommerce es un plugin gratuito desarrollado por GMETI. Para cualquier duda sobre privacidad, escríbenos a easy2cubaforwoo@gmeti.com.

Esta web y la demo

  • Sin cookies. No guardamos nada en tu navegador, así que no hace falta ningún aviso de cookies.
  • Visitas. Contamos cuántas personas visitan la web con GoatCounter, que no usa cookies ni guarda tu dirección IP ni datos que te identifiquen. Solo vemos totales, como el número de visitas, la página y el tipo de navegador.
  • Descargas. El número de descargas que ves en la portada se pide a GitHub desde tu navegador. Esa consulta no lleva datos tuyos.
  • Alojamiento. La web está en GitHub Pages. Como cualquier servidor, GitHub puede registrar tu dirección IP por seguridad, según su declaración de privacidad.
  • La demo. Lo que escribas en la demo se queda en tu navegador y se borra al cerrar o recargar la página. No se envía a ningún sitio.
  • Correo. Si nos escribes, usaremos tu correo solo para responderte.

El plugin en tu tienda

  • Los datos de los pedidos (quién compra, quién recibe, dirección, teléfonos y PDF de entrega) se guardan solo en tu WordPress. Nosotros no los recibimos.
  • Los PDF de entrega se envían desde tu propia web, con tu correo o con el SMTP que configures.
  • Para avisarte de versiones nuevas, el plugin consulta a GitHub cuál es la última versión. No envía datos de la tienda ni de los clientes.
  • El plugin añade un texto sugerido a Ajustes › Privacidad de WordPress y se integra con las herramientas de exportar y borrar datos personales. También puede borrar automáticamente los documentos antiguos.
  • Cada tienda que lo instala es responsable de su propia política de privacidad ante sus clientes.

Cambios

Si algo cambia, lo actualizaremos aquí con su nueva fecha.

Privacy

Your privacy

Last updated: October 15, 2026

In short: this website uses no cookies, asks for no data and does not track you. The plugin never sends us any data from your store or your customers.

Who is behind it

Easy2Cuba for WooCommerce is a free plugin developed by GMETI. For any privacy question, write to us at easy2cubaforwoo@gmeti.com.

This website and the demo

  • No cookies. We store nothing in your browser, so no cookie notice is needed.
  • Visits. We count visits with GoatCounter, which uses no cookies and does not store your IP address or anything that identifies you. We only see totals, such as visits, page and browser type.
  • Downloads. The download count on the home page is requested from GitHub by your browser. That request carries none of your data.
  • Hosting. The website is hosted on GitHub Pages. Like any server, GitHub may log your IP address for security, as described in its privacy statement.
  • The demo. Whatever you type in the demo stays in your browser and is cleared when you close or reload the page. It is not sent anywhere.
  • Email. If you write to us, we will only use your email to reply.

The plugin in your store

  • Order data (buyer, recipient, address, phones and delivery PDFs) is stored only in your WordPress. We never receive it.
  • Delivery PDFs are sent from your own website, using your email or the SMTP you set up.
  • To tell you about new versions, the plugin asks GitHub for the latest version. It sends no store or customer data.
  • The plugin adds suggested text to WordPress Settings › Privacy and works with the export and erase personal data tools. It can also delete old documents automatically.
  • Each store that installs it is responsible for its own privacy policy towards its customers.

Changes

If anything changes, we will update it here with a new date.
